## 개발 시작

```bash
git clone <저장소 주소>
cd kokkiri
npm install
cp .env.example .env.local   # 키는 팀 채널에서 받기 (절대 커밋 금지)
npm run dev                  # http://localhost:3000
```

- 스택: Next.js 15 (App Router) · TypeScript · Tailwind CSS · Vercel 배포
- Claude Code 쓰는 사람은 [CLAUDE.md](CLAUDE.md)가 자동으로 읽힌다
