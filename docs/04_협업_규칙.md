## 폴더 담당 (같은 파일을 두 명이 동시에 고치지 않는다)

```
src/app/kid/**            아이 화면 담당
src/app/parent/**         부모 화면 담당
src/app/api/**            LLM·API 담당
src/lib/llm/**            LLM·API 담당 (프롬프트·분류)
src/lib/types.ts          LLM·API 담당이 먼저 만들고, 바꿀 땐 팀 채널에 알림
src/lib/voice/**          음성 공용 모듈 (STT·TTS·보정) — 아이 화면 담당이 가져다 씀, 고칠 땐 팀 채널에 알림
src/app/voice-lab/**      음성 실험 페이지 (정확도 측정·목소리 고르기)
src/components/ui/**      디자인 담당 (공용 버튼·카드)
docs/**                   누구나, 단 05 결정 기록은 회의 결과만
```

- 남의 폴더를 고쳐야 하면 → 팀 채널에 먼저 말하고, 담당자가 고치거나 허락 후 수정

## 브랜치 · 커밋

- `main` = **항상 배포되는 상태.** Vercel이 main을 자동 배포한다
- 작업은 `이름/기능` 브랜치 → PR → 한 명이 훑어보고 머지 (예: `jaemo/kid-chat`)
- 커밋 메시지는 한국어 한 줄: `아이 대화 화면 선택지 버튼 추가`
- 머지 전에 `npm run build` 통과 확인 (빌드 깨지면 배포도 깨진다)
- `.env.local`, API 키, 원본 수집 데이터는 **절대 커밋 금지**

## Claude Code로 같이 작업할 때

- 저장소 루트의 `CLAUDE.md`를 자동으로 읽는다 → 아이템·규칙을 따로 설명할 필요 없음
- 한 컴퓨터에서 여러 작업을 병렬로 할 땐 git worktree 사용
  ```bash
  git worktree add ../kokkiri-kid -b 이름/kid-chat
  ```
- Claude한테 맡긴 결과도 **본인이 실행해 보고** PR 올린다
