# 06 도하 기획

도하(디자인·발표)가 따로 정리한 기획안이다. 팀 문서(01~05)와 다른 지점이 있어서, 합치기 전에 원안을 그대로 남긴다. 팀 문서에 실제로 반영한 내용과 원안에서 바뀐 점은 [07 도하 수정 기록](07_도하_수정_기록.md)에 있다.

- **[도하 결정]** 도하가 정한 것
- **[제안]** 기획 세션에서 나온 제안. 아직 정해지지 않았다
- **[가설]** 조사로 확인해야 하는 것

## 0. 도하 결정 요약

| # | 결정 |
| --- | --- |
| a | 부모가 보내고 싶은 질문은 코끼리가 다듬어 티키타카 도중에 자연스럽게 묻는다. 아이가 답하면 정리돼서 부모에게 자동 전송된다. 아이가 보내기를 누를 필요가 없고, 아이는 부모에게 전해진다는 사실을 모른다 |

| d | 디자인은 피그마 없이 코드 시안 + DESIGN.md + 아티팩트로 공유한다 |

## 1. 프로젝트 이해 [도하 결정]

- **문제:** 초등 저학년 부모가 아이와 정서적으로 멀어진다. 아이는 "학교 어땠어?"에 "그냥"으로 끝내고, 부모는 정말 궁금한 것(친구 문제, 서운한 것)을 직접 묻기 어렵다.
- **해결:** 코끼리 챗봇이 둘 사이의 전달자다. 부모가 묻기 어려운 질문을 다듬어 아이와의 대화 속에서 자연스럽게 묻고, 아이가 스스로 말하고 싶게 만든다. 아이는 답하면 코인(쌓이는 점수)을 받는다.
- **쌓이는 것:** 사진(달력 빨간 점), 대화 일기(파란 점), 감사 기록이 달력에 쌓이고, 몇 달 뒤 포토북으로 판매한다.
- **채점 연결:** 구현 20점("심사위원이 직접 입력해도 의미 있는 결과")에 질문을 다듬는 코끼리와 아이와 대화하는 코끼리가 정확히 맞는다.

## 2. 틀 안에서 다듬을 것

1. **코끼리는 얼굴이 둘 [제안]:** 아이에겐 궁금한 게 많은 사촌 형·언니(반말, 한 번에 질문 하나, 아기 말투·과한 감탄 없음), 부모에겐 통역사이자 코치(존댓말, 이유와 팁). 캐릭터 하나, 말투와 화면 둘.
2. **교환일기 구조 [제안]:** 부모도 질문에 답하고 일상을 공유하며, 아이도 부모 일상을 본다. 부모가 먼저 털어놓아야 아이도 말한다.
3. **부모 질문의 전달 방식 [도하 결정]:** 코끼리가 부모 질문을 다듬어 티키타카 도중에 묻고, 아이 답은 정리돼 부모에게 자동 전송된다. 아이는 전달 사실을 모른다.
   - 그 밖의 자유 대화를 부모에게 보낼지는 미정이다. [제안] 부모 질문에 대한 답만 전달한다.
4. **앱이 대화를 대신하지 않고 이어 준다 [제안]:** 아이 답 정리와 함께 "오늘 저녁엔 이렇게 물어보세요" 저녁 대화 카드를 부모에게 준다(실효성 근거).
5. **왜 코끼리 [제안]:** 큰 귀(잘 들어 줌) + 기억력(기록) → 포토북까지 이어지는 이야기.

## 3. 페르소나 [제안]

- **결제하는 부모:** 지은(38), 맞벌이 엄마, 초1 아들 준우. 귀가 19:30. 입학 후 학교 얘기가 궁금한데 아이는 "몰라". 친구 문제가 걱정돼도 캐물으면 닫을까 봐 못 묻는다. 폰에 아이 사진 수천 장, 정리 안 됨.
- **아이:** 준우(만 7세, 초1). 타자는 느리고, 좋아하는 상대에겐 말이 많다. 포인트·스티커를 좋아한다.
- **초1인 이유:** '초1의 벽'(입학 직후 맞벌이 가정의 돌봄 공백과 불안). 숫자 근거는 조사 필요.
- **디자인 영향:** 아이 쪽은 음성 입력, 읽어 주기, 탭 선택지가 기본.

## 4. 기능

### 데모 한 바퀴 (MVP이자 시연 대본) [제안, 2·3·4는 도하 결정 (a) 반영]

1. 부모가 코끼리에게: "준우가 요즘 친구 얘기를 안 해요"
2. 코끼리가 아이가 답하기 쉬운 질문으로 다듬는다. 부모는 원래 질문과 코끼리 버전을 나란히 본다.
3. 아이: 코끼리가 먼저 말 걸기 → 기분 날씨 탭 → 티키타카 도중 다듬은 질문 → 음성·선택지·사진으로 답 → 꼬리 질문 2~3번 → 코인 즉시
4. 답은 정리돼 부모에게 자동 전송된다(아이는 모름). 오늘 대화로 3줄 일기 제안 → 달력에 점
5. 부모: 답장 카드(아이 말 + 코끼리 메모 + 저녁 대화 카드) → 고마움 메시지 회신(코끼리가 아이에게 전함)
6. 주간 리포트 → 이전 대화 바탕의 다음 주 질문 추천
7. 데모 가족 3개월치 기록 → 포토북 미리보기 → 주문(가짜 결제)

### 틀 안에서 더할 것 [제안]

- 같은 질문에 둘 다 답해야 서로 공개되는 교환 질문
- 음성 입력과 코끼리 목소리
- 기분 날씨 체크인
- 저녁 대화 카드(물어볼 말, 피할 말)
- 두 폰 데모 모드: 데스크톱에서 부모·아이 화면을 나란히 띄운다. 심사위원이 혼자 양쪽을 체험하고, 발표 화면으로도 쓴다. (데모 모드를 두는 것 자체는 도하 결정 (c))

### 이번엔 뺄 것 [제안]

실제 결제·인쇄, 회원가입(데모 가족 코드로 입장), 자녀 여러 명, 실제 푸시, 네이티브 앱 빌드.

## 5. 유저 플로우 [제안]

| 누가 | 언제 | 흐름 |
| --- | --- | --- |
| 아이 | 하교 후 5분 | 코끼리 인사 → 기분 날씨 → 티키타카 속 질문에 답 → 꼬리 질문 → 코인 → 일기 3줄 확인 |
| 아이 | 심심할 때 | 자유 대화, 부모 일상 보기, 코인·보상 확인 |
| 부모 | 퇴근길 2분 | 답장 카드 → 저녁 대화 카드 → 오늘 질문 나도 답하기, 사진 1장 → 필요하면 코끼리에게 질문 부탁 |
| 부모 | 주 1회 5분 | 주간 리포트(마음 날씨, 자주 나온 친구·주제, 답 길이 변화) → 다음 주 질문 고르기 → 코인 충전 |

## 6. 비즈니스 모델 [가설, 가격은 조사 후 확정]

- **누가:** 초1~3 자녀를 둔 맞벌이 부모.
- **무엇을:** ① 월 코인 충전(예: 9,900원, AI 코끼리 포함) ② 우리 가족 책(3개월·6개월치 기록 자동 편집).
- **코인 [도하 결정 (b): 쌓이는 점수]:** 부모가 충전하면 아이가 대화로 벌고, 구간마다 보상(코끼리 꾸미기, 부모가 정한 소원 쿠폰)을 받는다. 많이 모이면 우리 가족 책. 현금 인출 없음.
- **왜 둘 다:** 포토북만 팔면 첫 매출이 몇 달 뒤인데 AI 비용은 첫날부터 나간다. 충전이 그 사이를 메운다.
- **왜 갈아타나:** 육아일기 앱은 부모가 쓰는 기록이고, 대화 카드·질문 일기는 부모가 직접 물어야 한다. 여기선 아이가 직접 말한 기록이 생기고 다른 데서 못 만든다. 쌓일수록 떠나기 어렵다. (경쟁 서비스는 조사로 확인)
- **첫 고객:** 팀원 지인 중 초등 저학년 부모 → 지역 맘카페·학부모 단톡.
- **확장:** 조부모 공유, 책 추가 인쇄.

## 열린 쟁점 (발표 Q&A 대비)

아이 모르게 부모에게 전달하는 구조는 심사에서 윤리 질문이 나올 가능성이 크다. 준비할 답변:

- 만 14세 미만은 보호자 동의 대상이고, 결제·가입 주체가 부모다.
- 전달되는 건 부모 질문에 대한 답의 요약이다.
- 코끼리는 "비밀로 해 줄게"라고 약속하거나 거짓말하지 않는다.
- 위험 신호 대응.

이 원칙들은 팀과 확정해야 한다. 팀 문서의 "비밀 보장 3단계"(01 4장)와 부딪히는 지점이 있다.
