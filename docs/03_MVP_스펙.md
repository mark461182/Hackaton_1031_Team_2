# 03 MVP 스펙

**원칙: 하나의 흐름이 처음부터 끝까지 진짜로 돌아간다.** 기능 개수보다 심사위원이 직접 해 봤을 때 결과가 나오는 게 중요하다 (구현 40점).

## 만드는 것 / 안 만드는 것

| 만든다 (MVP) | 발표 장표로만 | 안 만든다 |
| --- | --- | --- |
| 아이 ↔ 코끼리 대화 | 가족 스토리북 미리보기 | 실제 결제·충전 |
| 대화 분류 (일상 / 공유 제안 / 위험) | 주간 "마음 날씨" | 회원가입·이메일 인증 |
| 공유 제안 → 아이 동의 → 부모 전달 | 학교·교육청 연결 | 푸시 알림 (화면 안 알림으로 대체) |
| 위험 신호 → 부모 알림 (원문 없이) + 대화 가이드 | | 사진 편집 |
| 부모 → 코끼리 → 아이 질문 전달 | | |
| 달력 기록 (대화 = 파란 점, 사진 = 빨간 점) | | |
| 코인 숫자 표시 (가상, 행동에만) | | |
| "예시 가족으로 체험하기" | | |

## 화면

```
/                     역할 선택: [부모] [아이] [예시 가족으로 체험하기]
/kid                  코끼리 대화 (메인)
/kid/calendar         내 기록 달력
/parent               알림·공유된 이야기 목록
/parent/ask           아이에게 질문 보내기 (코끼리가 말투 변환)
/parent/calendar      가족 달력
```

## 핵심 흐름

```
[아이] 코끼리와 대화
   │
   ▼
[서버] 메시지마다 LLM 분류 ─────────────┬───────────────┬────────────────┐
                                     일상            공유 제안          위험 신호
                                       │               │                 │
                                  저장만 함      코끼리: "엄마한테       코끼리: "이건 어른이
                                  (부모 X)       같이 말해 볼까?"        도와줘야 해서 엄마한테
                                                    │                  알려줄게. 네 말 그대로는
                                              아이 [좋아]/[싫어]        안 보여줄게"
                                                    │                       │
                                              좋아 → 부모에게           부모에게 알림:
                                              아이가 고른 내용          상황 요약(원문 X)
                                                                      + 대화 가이드
```

```
[부모] "요즘 친구랑 어때?" 입력
   → LLM이 아이 말투로 변환: "요즘 같이 노는 친구 중에 제일 웃긴 친구는 누구야?"
   → 아이의 코끼리 대화창에 코끼리가 먼저 말을 거는 형태로 등장
```

## API (초안)

| 메서드 | 경로 | 하는 일 |
| --- | --- | --- |
| POST | `/api/kid/chat` | 아이 메시지 → 코끼리 답 + 분류 결과 |
| POST | `/api/kid/share/:id` | 공유 제안에 아이가 좋아/싫어 |
| GET | `/api/parent/feed` | 공유된 이야기 + 알림 |
| POST | `/api/parent/ask` | 부모 질문 → 아이 말투 변환 후 전달 |
| GET | `/api/calendar?role=` | 달력 기록 |

## LLM 프롬프트 요구사항

**코끼리 말투**
- 초등 1~3학년이 읽을 수 있는 짧은 문장, 한 번에 질문 1개
- 평가·훈계·정답 제시 금지. 공감 → 열린 질문 ("그때 기분이 어땠어?")
- 유치한 아기 말투 금지 (도하 메모: 친근함을 늘리려고 유치하게 말하면 효과 없음)
- 선택지 버튼을 같이 제시할 수 있게 JSON으로 응답

**분류 기준**
- `risk`: 맞음·괴롭힘·따돌림·협박, 자해·죽고 싶다, 어른의 부적절한 접촉·비밀 강요, 낯선 사람, 학대 의심
- `share`: 부모가 알면 아이에게 도움이 되는데 아이가 망설이는 이야기 (서운함, 실수, 걱정)
- `daily`: 그 외
- 애매하면 `risk`로 올리지 말고 `share`로 → 오탐으로 아이 신뢰를 깨지 않는다
- 부모 알림 문장에 **아이 발화 원문·인용 금지**

**응답 형식 (예)**
```json
{ "reply": "많이 속상했겠다. 그 친구가 언제부터 그랬어?",
  "choices": ["어제부터", "꽤 오래됐어", "말하기 싫어"],
  "category": "risk",
  "parentSituation": "학교에서 친구 관계로 힘든 일이 있는 것 같아요",
  "parentGuide": "혼내지 않을 거라고 먼저 말해 주고, '요즘 짝꿍이랑은 어때?'로 시작해 보세요" }
```

## 데모 체크 (심사위원 시점)

- [ ] 배포 URL 접속 → 설명 없이 "예시 가족으로 체험하기"를 누를 수 있다
- [ ] 아이로 "짝꿍이 맨날 때려" 입력 → 코끼리가 공감하고 예외를 솔직하게 말한다
- [ ] 부모 화면에 원문 없이 알림 + 가이드가 뜬다
- [ ] 아이로 "급식에 떡볶이 나왔어" → 부모 화면에 안 뜬다
- [ ] 부모가 보낸 질문이 아이 말투로 바뀌어 코끼리 대화에 나타난다
- [ ] 달력에 점이 찍힌다
- [ ] 서로 다른 입력 → 서로 다른 결과 (고정 답변 아님)
