# 02 데이터 근거

발표·문제 정의에 쓰는 숫자의 출처. **숫자를 발표에 쓸 때는 이 문서의 값만 쓴다.**

## 어떻게 모았나

- **출처:** 네이버 검색 > 카페 탭, 최근 1년, 관련도순 (검색 미리보기 = 제목·본문 앞부분·댓글 일부)
- **방식:** 문제를 미리 정하지 않고, 고민 표현 × 학부모 맥락으로 넓게 수집
  - 고민 말 23개: 고민, 답답, 막막, 힘들어요, 지쳐요, 스트레스, 속상, 걱정, 어떡하죠, 다들 어떻게 하세요, 저만 그런가요, 돈 아까워요, 포기, 후회 …
  - 맥락 8개: 초등맘, 학부모, 워킹맘, 맞벌이 엄마, 초1 엄마, 초등 고학년 엄마, 중1 엄마, 아이 키우면서
  - 184개 조합 × 검색어당 약 90건
- **결과:** 글 **9,282건** (URL 중복 제거) → Claude(Sonnet)로 판별한 학부모 고민 **6,463건** → 미리 정한 분류 없이 주제 **23개**로 묶음
- **수집 코드:** 별도 저장소 `parent-pain` (scrape.py → label.py → cluster.py → export.py)
- **원본 글은 이 저장소에 올리지 않는다** (개인 작성 글. 집계 숫자와 짧은 요약 인용만 사용)

## 한계 (질문 받으면 이렇게 답한다)

- 검색 미리보기만 봤다 (본문 전체 아님)
- "숨김·늦게 앎" 107건은 키워드 기반 추정이다
- 고민 글만 모았으므로 "전체 학부모의 몇 %"라고 말하면 안 된다 → "고민 글 중 몇 건"으로만 말한다
- 지불 의향은 이 데이터로 증명되지 않는다 → 인터뷰로 보강 [확인 필요]
