# 07 도하 수정 기록

> **정정 메모 (11/1):** PR #2 때의 기록이다. 4장 "팀과 맞춰야 할 것"은 11/1 결정 시트로 정했고, 기준은 [05 결정 기록](05_결정_기록.md)이다.

이 PR에서 도하가 고른 안으로 팀 문서를 고쳤다. 표, 장 번호, 문서 이름은 그대로 두고 내용만 바꿨다. **리뷰는 이 문서부터 보면 된다.** 원안은 [06 도하 기획](06_도하_기획.md)에 있다.

## 1. 도하가 고른 것

| 쟁점 | 전 (팀 문서) | 후 (도하 선택) |
| --- | --- | --- |
| 핵심 문제 | 아이가 숨기는 일을 부모가 늦게 안다 | 그대로 두고, 해법으로 "부모가 묻기 어려운 질문을 코끼리가 대신 묻는다"를 얹음 |
| 코끼리 | 아이의 친구 | 아이에겐 친구(반말), 부모에겐 코치(존댓말, 이유와 팁) |
| 부모 질문의 답 | 부모 질문은 아이 말투로 바꿔 전달까지. 아이 이야기는 아이가 [좋아]를 눌러야 부모에게 감 | 코끼리가 대화 도중 자연스럽게 묻고, 아이 답은 **자동으로** 부모에게 감. **아이는 전달 사실을 모름** |
| 코끼리의 첫 약속 | "위험한 일은 어른한테 꼭 알려야 해. 그것 말고는 너랑 나만 아는 비밀이야" | "비밀" 약속을 하지 않음. 부모에게 전달된다는 사실도 아이에게 말하지 않음 |
| 부모 화면의 아이 말 | 원문·인용 금지 (CLAUDE.md 절대 규칙 1번) | 답장 카드에 아이 답 원문 + 코끼리 요약·메모. 절대 규칙 1번 삭제 |
| 자유 대화 | 일상 / 공유 제안 / 위험 3분류 | 그대로. 여기에 "부모 질문의 답" 길을 하나 더함 |
| 코인 주는 때 | 사진·생활 미션에만, 가상 기록 | **대화를 마쳤을 때 + 일상 사진 공유.** 생활 미션(집안일)과 기분 날씨 체크인은 뺌 |
| 코인 쓰는 곳 | 숫자 표시만 | **기프티콘 교환.** 코끼리 꾸미기는 시간 나면 |
| 수익 모델 | 안심 구독 월 6,900원 + 스토리북 건당 | **코인 충전 + 기프티콘 수수료**(메인) + 스토리북 건당 + 광고(추후 검토). 월 가격 없음 |
| 가족 스토리북 | 발표 장표로만 | 미리보기 + 주문(가짜 결제)까지 구현 |
| 3분 데모 | 아이의 위험 이야기에서 시작 | 부모 질문 → 아이 답 → 답장 카드 먼저, 위험 장면은 뒤에 |
| 더한 기능 | | 두 폰 데모 모드, 원래 질문·코끼리 버전 나란히, 코끼리 말 읽어 주기, 오늘 대화로 3줄 일기, 주간 리포트 + 다음 주 질문 추천, 차별성에 육아일기 앱·대화 카드 |

## 4. 팀과 맞춰야 할 것

1. **05 미정과 다름:** #2(부모에게 무엇을 보여주나), #3(예외 규칙을 아이에게 알리나), #4(코인), #5(수익 모델)의 "제안" 칸과 이 PR이 반대다. 머지 전에 회의에서 정하고 05를 고친다
2. **위험 알림에 원문을 넣을지:** 절대 규칙은 지웠지만 위험 알림은 지금 상황 요약만 쓴다
3. **코인이 쌓이는 점수인지:** 06 원안은 "쓰면 없어지지 않고 쌓이는 점수"였는데, 기프티콘으로 바꾸면 쓸 때 줄어든다. 01·03은 기프티콘 교환 기준으로 썼다
4. **월 가격이 빠짐:** 채점 B 수익 15점은 "얼마"를 본다. 충전 단위와 수수료율 숫자가 필요하다 (01 5장)
5. **코인 수수료:** 05 #5는 "규제·명분 약함"으로 뺀 안이다. 선불 결제 규제 여부를 멘토링에서 확인한다 (01 5장)
6. **발표 Q&A:** 01 맨 위 "감시 앱이 아닙니다"는 그대로 뒀다. 아이 모르게 원문을 전하는 구조와 같이 쓰면 바로 반박이 나올 수 있어서, 4장 Q&A 답을 팀과 확정해야 한다
7. **구현 범위:** MVP 표에 기능이 늘었다(주간 리포트, 스토리북 가짜 결제, 기프티콘, 두 폰 모드, 3줄 일기). 03:00 이후 새 기능 금지 규칙이 있으니 우선순위를 정한다
8. **안 넣은 것:** 저녁 대화 카드(답장 카드는 아이 답 + 요약·메모만), 페르소나, 교환일기, 부모 고마움 회신은 이번 PR에 넣지 않았다. 06에는 남아 있다
9. **역할 표기(04):** 추후 정한다
