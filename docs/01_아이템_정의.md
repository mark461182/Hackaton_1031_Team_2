# [서비스명] — 부모님한테 못 하는 말, 코끼리한테는 할 수 있어

> **한 줄:** 아이는 부모라서 숨기는 이야기가 있고, 부모는 정말 궁금한 걸 캐물으면 아이가 닫을까 봐 묻지 못한다. 친구 코끼리가 부모 대신 대화 속에서 자연스럽게 묻고, 아이의 답을 부모에게 전한다. 위험한 일이 생기면 부모가 늦지 않게 알도록 돕는 서비스
> **마지막 한 문장:** "감시 앱이 아닙니다. 아이가 혼자 감당하지 않게 하는 친구입니다."

## 0. 한 문장 비유 — "금쪽이 코끼리를 매일 집에서"

- 「요즘 육아 금쪽같은 내 새끼」에서 부모에게는 폭주하던 아이가 **말하는 코끼리 스피커**에게는 "사실 엄마가 사라질까 봐 무서워" 같은 본심을 털어놓는다. 우리가 만드는 경험이 정확히 이것
- **발표 문장:** "방송에서는 오은영 박사와 제작진이 코끼리 뒤에서 질문을 설계합니다. 하지만 우리 집에는 오은영 박사가 없습니다."
- 그래서 **음성 대화가 핵심**이다. 코끼리가 말로 묻고, 아이가 말로 답한다 (화면 글자·버튼은 대체 수단)
- 방송의 쟁점("유도 질문으로 원하는 답을 끌어내는 것 아니냐")에 대한 우리의 답 = **코끼리는 답을 유도하지 않는다.** "엄마 좋지?"가 아니라 "그때 기분이 어땠어?"

**이름·캐릭터 주의:** "금쪽이"는 채널A 캐릭터이고 아이오테드가 라이선스 계약으로 「금쪽이 스피커」를 상품화했다. → 서비스 이름·캐릭터 디자인·목소리(방송에 쓰인 클로바더빙 "하준")를 비슷하게 만들지 않는다. 발표에서 "금쪽이 코끼리 같은"이라고 **비유로만** 말한다.

| --- | --- | --- |
| 목적 | AI 교육용 — 학생이 챗봇·프롬프트를 설계하며 AI를 배움 | 본심을 털어놓는 친구 + 부모와의 다리 |
| 어디서 | 학교·교육기관 | 집 |
| 누가 돈을 내나 | 학교 | 학부모 |
| 형태 | 하드웨어 스피커 | 앱 (휴대폰·태블릿) |

## 1. 문제 근거

**우리가 직접 수집한 데이터 (네이버 카페 학부모 글 9,282건 → 학부모 고민 6,463건 분류)**
- 또래관계·학교폭력·따돌림 주제 **341건** (초저 170건, 초고 73건): 부모가 가장 두려워하는 건 아이가 밖에서 혼자 겪는 일
- 아이가 숨겼거나, 부모가 몰랐거나, 늦게 알았다는 신호가 있는 글 **107건**, 초저가 28건으로 최다

  - "초1 아이가 짝꿍에게 **매일 맞고 놀림받는데** 학교에 알릴지 망설임"
  - "사립초 입학 한 달, 아이가 **학교 얘기를 안 해** 불안하다"
  - "아이가 친구와 통화하며 **욕하는 걸 듣고 충격**"

**팀 리서치**
- 초등 저학년 가정의 실제 대화를 분석했더니, 엄마의 화제가 학습 확인과 훈계로 이어지고 아이는 "응", "알았어"로 짧게 답함 (초등 저학년 부모·자녀 의사소통 연구, 3가정)

- 서울학부모지원센터 양육자 집단상담: 80개 집단, 941명 참여

## 3. 3분 핵심 시나리오 (데모)

두 폰 데모 모드(왼쪽 부모, 오른쪽 아이)로 진행한다. 아래 코끼리 대사는 예시이고 실제 말은 챗봇 담당이 정한다.

1. **부모 화면:** "준우가 요즘 친구 얘기를 안 해요" 입력 → 원래 질문 옆에 코끼리 버전 "요즘 같이 노는 친구 중에 제일 웃긴 친구는 누구야?"가 뜸
2. **아이 화면:** 코끼리가 먼저 소리로 인사 "오늘 학교에서 뭐가 제일 재밌었어?" → 이야기 도중 코끼리가 궁금한 것처럼 다듬은 질문을 꺼냄 (부모 질문이라고 밝히지 않음)
3. **아이:** 말로 답함 → 꼬리 질문 2~3번 → 대화를 마치면 코인
4. **부모 화면:** 답장 카드가 자동으로 뜸 (아이 답 + 코끼리 요약·메모). 오늘 대화로 만든 3줄 일기가 달력에 파란 점으로 찍힘
5. **위험 장면:** 아이 "짝꿍이 맨날 내 필통 뺏고 때려. 엄마한테 말하면 학교 가서 난리 칠까 봐 말 안 했어" → 코끼리가 공감 "많이 힘들었겠다. 그런 일은 혼자 참지 않아도 돼" → 부모 화면에 위험 신호 알림(아이 말 1~2문장 + "친구 관계에서 힘든 일이 있는 것 같아요") + 대화 가이드("혼내지 않을게, 요즘 짝꿍이랑은 어때?"로 시작하세요)
6. **비교:** 일상 이야기("급식에 떡볶이 나왔어")는 답장 카드·알림으로 가지 않음 (3줄 일기에는 들어감)
7. **마무리:** 주간 리포트 + 다음 주 질문 추천 → 가족 스토리북 미리보기 → 주문(가짜 결제) → 아이는 모은 코인으로 기프티콘을 고름

| 1. 일상 | 그 외 이야기 ("급식에 떡볶이 나왔어") | ~~없음 (저장만)~~ → 답장 카드·알림은 없음. 오늘 3줄 일기·주간 리포트·스토리북에는 들어감 (11/1) |
| 2. 부모 질문의 답 | 부모가 맡긴 질문을 코끼리가 다듬어 대화 도중 자연스럽게 묻고 아이가 답함. 아이는 부모 질문이라는 것도, 전달된다는 것도 모름 | 아이 답 원문 + 코끼리 요약·메모 (자동, 답장 카드). 답이 위험이면 위험 알림 하나로. "말하지 마" 내용은 빠짐 |
| 3. 다리 역할 | 코끼리가 "엄마한테 같이 말해 볼까?"로 설득, 아이가 OK 하면 전달 | 아이가 고른 내용. [싫어]면 일기에서도 빠짐 |
| 4. 위험 신호 | 괴롭힘·폭력·자해·학대·낯선 어른 등 | ~~상황 요약 + 대화 가이드~~ → 아이 말 1~2문장 + 상황 요약 + 대화 가이드 (자동, 11/1). 가족이 당사자면 알림 없음 |

- **코끼리는 비밀을 약속하지 않음:** "비밀로 해 줄게", "너랑 나만 아는 비밀"이라고 말하지 않는다. 부모 질문은 코끼리가 궁금한 것처럼 묻고, 부모에게 전달된다는 사실은 아이에게 알리지 않는다
- **위험할 때:** 코끼리는 공감하고 "혼자 참지 않아도 돼. 엄마나 선생님한테 말해 보는 건 어때?"처럼 아이가 직접 어른에게 말하도록 권한다. 부모 알림은 아이에게 알리지 않고 간다
- **가족이 당사자일 때:** 부모 알림을 띄우지 않고, 코끼리가 다른 믿을 만한 어른에게 도움을 청하도록 권한다. 발표 답: 실서비스는 아동보호 전문기관과 연계 (11/1)
- **예상 질문 "감시 앱 아닌가요?"** → 부모에게 가는 건 부모가 물은 질문의 답, 위험 신호, 하루 3줄 일기다. 대화 원문이 그대로 가지 않고, 아이가 말하지 말라고 한 것과 [싫어]한 것은 빠진다 (11/1에 일상도 일기에는 들어가는 것으로 바뀜). 가입·결제·동의 주체는 부모. 목표는 감시가 아니라 부모가 아이에게 다시 말을 걸 수 있게 하는 것 [발표 담당(도하)이 확정]
- **예상 질문 "코인 주면 억지로 말하지 않나요?"** → 코인은 대화를 마쳤을 때와 일상 사진을 공유했을 때, 최소 기준과 횟수 제한을 두고 줌. 무엇을 말했는지(비밀·감정)에 따라 주지 않음
- **만 14세 미만:** 부모가 가족 계정을 만들고 동의(법정대리인 동의)
- **음성은 저장하지 않음:** 아이 목소리는 민감한 개인정보 → 녹음 파일은 남기지 않고 받아쓴 글자만 저장 → "아이 목소리 데이터는요?"에 대한 답
- **유도 질문 금지:** 원하는 답을 끌어내는 질문을 하지 않음 (방송 쟁점에 대한 답)
- **위험 판단 오류 대비:** 알림은 "확정"이 아니라 "살펴봐 주세요" 수준. 진단·판정하지 않음
- **효과 과장 금지:** "학폭을 막는다"가 아니라 "부모가 늦지 않게 알도록 돕는다"까지만 주장
