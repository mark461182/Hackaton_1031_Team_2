# [서비스명] — 부모님한테 못 하는 말, 코끼리한테는 할 수 있어

> **한 줄:** 아이는 부모라서 숨기는 이야기가 있다. 친구 코끼리에게는 솔직하게 털어놓고, 코끼리는 그 비밀을 지키면서 아이가 부모에게 직접 말할 수 있게 다리를 놓아준다. 위험한 일이 생겼을 때만 부모가 늦지 않게 알도록 돕는 서비스
> **마지막 한 문장:** "감시 앱이 아닙니다. 아이가 혼자 감당하지 않게 하는 친구입니다."

## 0. 한 문장 비유 — "금쪽이 코끼리를 매일 집에서"

- 「요즘 육아 금쪽같은 내 새끼」에서 부모에게는 폭주하던 아이가 **말하는 코끼리 스피커**에게는 "사실 엄마가 사라질까 봐 무서워" 같은 본심을 털어놓는다. 우리가 만드는 경험이 정확히 이것
- **발표 문장:** "방송에서는 오은영 박사와 제작진이 코끼리 뒤에서 질문을 설계합니다. 하지만 우리 집에는 오은영 박사가 없습니다."
- 그래서 **음성 대화가 핵심**이다. 코끼리가 말로 묻고, 아이가 말로 답한다 (화면 글자·버튼은 대체 수단)
- 방송의 쟁점("유도 질문으로 원하는 답을 끌어내는 것 아니냐")에 대한 우리의 답 = **코끼리는 답을 유도하지 않는다.** "엄마 좋지?"가 아니라 "그때 기분이 어땠어?"

**이름·캐릭터 주의:** "금쪽이"는 채널A 캐릭터이고 아이오테드가 라이선스 계약으로 「금쪽이 스피커」를 상품화했다. → 서비스 이름·캐릭터 디자인·목소리(방송에 쓰인 클로바더빙 "하준")를 비슷하게 만들지 않는다. 발표에서 "금쪽이 코끼리 같은"이라고 **비유로만** 말한다.

| --- | --- | --- |
| 목적 | AI 교육용 — 학생이 챗봇·프롬프트를 설계하며 AI를 배움 | 본심을 털어놓는 친구 + 부모와의 다리 |
| 어디서 | 학교·교육기관 | 집 |
| 누가 돈을 내나 | 학교 | 학부모 |
| 형태 | 하드웨어 스피커 | 앱 (휴대폰·태블릿) |
| 부모 연결 | 확인된 바 없음 [발표 전 재확인] | 비밀 보장 3단계로 부모에게 전달 |

## 3. 3분 핵심 시나리오 (데모)

1. **아이 화면:** 코끼리 "오늘 학교에서 기분이 어땠어? 나한테만 말해도 돼"
2. **아이:** "짝꿍이 맨날 내 필통 뺏고 때려. 엄마한테 말하면 학교 가서 난리 칠까 봐 말 안 했어"
3. **코끼리:** 공감하며 들어줌 → "많이 힘들었겠다. 이건 어른이 도와줘야 하는 일이라서, 엄마한테 알려줘야 해. 대신 네가 한 말 그대로는 안 보여줄게"
4. **부모 화면:** 위험 신호 알림 "친구 관계에서 힘든 일이 있는 것 같아요" + 대화 가이드("혼내지 않을게, 요즘 짝꿍이랑은 어때?"로 시작하세요)
5. **비교:** 일상 이야기("급식에 떡볶이 나왔어")는 부모에게 가지 않고, 아이가 "엄마한테도 말해줘" 한 것만 공유됨 → 달력에 기록

## 4. 비밀 보장 3단계 약속 (서비스의 핵심)

| 단계 | 내용 | 부모에게 가는 것 |
| --- | --- | --- |
| 1. 비밀은 비밀 | 아이가 코끼리에게 한 말의 원문은 전달하지 않음 | 없음 |
| 2. 다리 역할 | 코끼리가 "엄마한테 같이 말해 볼까?"로 설득, 아이가 OK 하면 전달 | 아이가 고른 내용 |
| 3. 위험할 때만 예외 | 괴롭힘·폭력·자해·학대·낯선 어른 등 위험 신호 | 원문 없이 상황 요약 + 대화 가이드 |

- **아이에게 처음부터 솔직하게 알림:** "위험한 일은 어른한테 꼭 알려야 해. 그것 말고는 너랑 나만 아는 비밀이야" → 학교 상담 선생님의 비밀 보장 원칙과 같은 구조. 아이를 속이는 구조는 만들지 않음
- **예상 질문 "감시 앱 아닌가요?"** → 원문을 보여주지 않고, 예외 기준을 아이에게도 공개함. 목표는 감시가 아니라 아이가 혼자 감당하지 않게 하는 것
- **예상 질문 "비밀 말하면 코인 주면 억지로 하지 않나요?"** → 털어놓는 것에는 보상하지 않음. 코인은 사진·생활 미션 같은 행동에만
- **만 14세 미만:** 부모가 가족 계정을 만들고 동의(법정대리인 동의)
- **음성은 저장하지 않음:** 아이 목소리는 민감한 개인정보 → 녹음 파일은 남기지 않고 받아쓴 글자만 저장 → "아이 목소리 데이터는요?"에 대한 답
- **유도 질문 금지:** 원하는 답을 끌어내는 질문을 하지 않음 (방송 쟁점에 대한 답)
- **위험 판단 오류 대비:** 알림은 "확정"이 아니라 "살펴봐 주세요" 수준. 진단·판정하지 않음
- **효과 과장 금지:** "학폭을 막는다"가 아니라 "부모가 늦지 않게 알도록 돕는다"까지만 주장
