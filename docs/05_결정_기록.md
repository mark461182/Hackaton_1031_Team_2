# 05 결정 기록

회의에서 정한 것만 적는다. **"미정"이 남아 있으면 얼라인이 안 된 것.**

## 미정 — 얼라인 회의 안건

| # | 질문 | 선택지 | 제안 |
| --- | --- | --- | --- |
| 1 | 핵심 가치는 무엇인가 | (a) 아이가 숨기는 비밀을 털어놓는 친구 + 위험할 때만 부모에게 (b) 부모·자녀 일상 공유·감사 기록 (c) 둘 다 | **(a)를 중심, (b)는 달력·스토리북으로 보조** |
| 2 | 부모에게 무엇을 보여주나 | 원문 전부 / 아이가 고른 것 + 위험 알림(원문 X) / 기분 흐름만 | **아이가 고른 것 + 위험 알림** (비밀 보장 3단계) |
| 3 | 예외 규칙을 아이에게 알리나 | 처음부터 알림 / 숨김 | **처음부터 알림** (숨기면 감시 앱 → 윤리 질문에서 무너짐) |
| 4 | 코인 | 실제 돈 / 가상 기록 / 없음 | **가상 기록, 행동(사진·미션)에만.** 비밀 털어놓기에는 보상 X |
| 5 | 수익 모델 | 안심 구독 / 스토리북 건당 / 코인 수수료 / 광고 | **안심 구독 월 6,900원 + 스토리북 건당** (코인 수수료는 규제·명분 약함) |
| 6 | 타깃 학년 | 초1~3 / 초4~6 | **초1~3** (학교라는 새 사회 + 사춘기 전 습관) |
| 7 | LLM | 래블업 토큰팩토리(해커톤 제공) / AWS Bedrock($200 바우처) / 기타 | 키 받는 즉시 결정. 한국어 대화 품질 먼저 테스트 |
| 8 | DB | Supabase / 데모용 메모리+localStorage | 시간 부족하면 **데모용 저장**으로 시작 → 여유 있으면 Supabase |
| 9 | 로그인 | 없음(예시 가족) / 구글 / 자체 | **없음 + 예시 가족** (테스트 계정 제출 불필요) |
| 10 | 서비스·캐릭터 이름 | | |
| 11 | 역할 분담 | [04 협업 규칙](04_협업_규칙.md) 표 | |
